WEB KASIR SUMBER BERKAH SIDOGURO
================================

Dokumentasi utama project telah dipindahkan ke README.md agar lebih mudah
dibaca di GitHub dan platform hosting kode.

Lihat README.md untuk:
- fitur aplikasi;
- menjalankan project secara lokal;
- setup Supabase;
- environment variables;
- deployment Vercel;
- endpoint health API; dan
- struktur folder project.

Untuk penggunaan lokal yang tersinkron, jalankan `npm start`. Anda dapat membuka
http://localhost:3000 atau tetap memakai Live Server di http://127.0.0.1:5501.
Jika memakai Live Server, `npm start` tetap harus berjalan di terminal lain.

Jangan menyimpan file .env atau secret apa pun ke repository.
